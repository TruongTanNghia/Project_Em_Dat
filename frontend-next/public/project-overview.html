01Tổng quan

Sáu pipeline độc lập gom về một backend chung và một giao diện chung.

ADA Medical AI Suite nhận đầu vào ở định dạng chuẩn lâm sàng (EDF, NIfTI, DICOM, JSON, ảnh), trả về kết quả JSON cùng visualization tương ứng. Mỗi pipeline trained trên dataset chuẩn quốc tế hoặc Việt Nam, không phải mockup.

Live · Frontend deploy tại project-em-dat.vercel.app. Backend Python chạy local, expose qua ngrok HTTPS tunnel. live

02Sáu module

Bốn module production, hai đang phát triển. Mỗi module có endpoint /api/predict-* riêng.

01 EEG · Phát hiện cơn động kinh production

Phân loại từng cửa sổ 4 giây của tín hiệu EEG 23 kênh thành normal / seizure. CNN spatial · BiGRU temporal · Attention.

ROC-AUC · CHB-MIT
0.84
Method
PyTorch CNN + BiGRU + Attention
Dataset
CHB-MIT Scalp EEG (24 BN nhi)
Output
p(seizure) per window, burst timestamp
Endpoint
POST /api/predict-edf
02 Brain MRI · Phân đoạn u não production

Phân đoạn 3D 4 channel (FLAIR + T1 + T1c + T2) ra ba lớp NCR / ED / ET. Mesh 3D extract qua marching cubes.

Dice WT · BraTS 2020
0.83
Method
Keras 3D U-Net + 4-way TTA
Dataset
BraTS 2020, 369 ca, 4 channel MRI
Output
volumetric mask + cm³ + mesh GLB
Endpoint
POST /api/predict-brain
03 Lung CT · Định vị nốt phổi production

Segment nốt phổi trên CT, tính đường kính mm theo affine, score malignancy 1–5 theo consensus 4 radiologist.

mIoU · LIDC-IDRI
0.71
Method
PyTorch DeepLabV3
Dataset
LIDC-IDRI, ~1,018 CT
Output
mask + ø(mm) + malignancy 1–5
Endpoint
POST /api/predict-lung
04 Blood panel · Đọc xét nghiệm máu production

Rule-based engine cross-check CBC + Lipid + Glucose với reference range chuẩn lab, gắn cờ giá trị bất thường, tính risk score đa chiều.

Method
Rule-based engine (no GPU)
Panels
CBC · Lipid · Glucose · HbA1c
Output
flagged values + risk score
Endpoint
POST /api/predict-blood
05 Breast · Phát hiện khối u vú new in dev

Phát hiện và phân loại khối u vú trên siêu âm (BUSI) và nhũ ảnh (CBIS-DDSM). U-Net segment + EfficientNet-B4 classify, output gắn nhãn BI-RADS 0–6.

Target AUC · BUSI + CBIS-DDSM
0.88
Method
EfficientNet-B4 (cls) + U-Net (seg)
Datasets
BUSI · CBIS-DDSM, ~3,200 ảnh
Output
mask + BI-RADS 0–6 + p(malignant)
Endpoint
POST /api/predict-breast (planned)
06 Spine · Phân tích cột sống X-quang new in dev

Detect từng đốt sống trên X-quang lateral, classify 7 bệnh lý phổ biến: wedge / burst fracture, osteophyte, spondylolisthesis, scoliosis, disc degeneration, vertebral collapse.

Target mAP · VinDr-SpineXR
0.55
Method
YOLOv8 detect + ResNet50 classify
Datasets
VinDr-SpineXR, ~10,000 X-quang
Output
bbox per vertebra + label + severity
Endpoint
POST /api/predict-spine (planned)

07Local development

Cần 3 terminal song song.

# 1. Backend Flask AI service              → port 5000
cd backend
python python_api.py

# 2. Frontend Next.js dev server           → port 3000
cd frontend-next
npm install        # lần đầu
npm run dev

# 3. ngrok HTTPS tunnel                    (nếu cần)
ngrok http 5000

Sau khi ngrok in HTTPS URL: Vercel → Settings → Environment Variables → cập nhật BACKEND_URL → Deployments → Redeploy bản mới nhất, bỏ tick Use existing Build Cache.

08Status & roadmap

Đang ở đâu, đi đâu tiếp.

Q3 2025

EEG seizure detection · production

CNN + BiGRU + Attention trained CHB-MIT, ROC-AUC 0.84. Endpoint live.

Q4 2025

Brain MRI + Lung CT + Blood panel · production

3D U-Net BraTS, DeepLabV3 LIDC, rule-based blood. Tất cả live.

Q1 2026

Frontend migrate sang Next.js · Vercel deploy

Đổi từ Express legacy sang Next.js 16, deploy public với ngrok tunnel cho BE.

Q2 2026 · now

Module 05 + 06 · Breast & Spine

Chuẩn bị dataset BUSI + CBIS-DDSM (breast) và VinDr-SpineXR (spine), baseline EfficientNet-B4 + YOLOv8.

Q3 2026 · planned

Move backend khỏi ngrok

Container hoá Flask, deploy lên Render hoặc Fly.io để không phụ thuộc máy local.
